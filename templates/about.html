About Our Project

Automated Certificate Generator System

The Automated Certificate Generator System is a web-based application developed using Python and Flask. It automatically generates certificates for students using an Excel file or individual student details.


Project Features

  • ✅ Admin Login
  • ✅ Dashboard
  • ✅ Single Certificate Generation
  • ✅ Multiple Certificate Generation
  • ✅ Upload Excel File
  • ✅ Search Certificate
  • ✅ Certificate History
  • ✅ Download Certificate
  • ✅ Download ZIP File
  • ✅ Export Student Details
